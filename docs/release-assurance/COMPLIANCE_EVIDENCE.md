# Compliance Evidence Boundary

Do not claim a certification merely because DDF implements technical controls.

For every compliance claim intended for release materials, record:

- framework / jurisdiction
- exact claim wording
- control/evidence mapping
- evidence owner
- reviewer/assessor
- review date
- scope
- exclusions
- expiration/review date

Examples may include SOC 2, ISO 27001, GDPR-related controls or sector-specific
requirements, but a claim is permitted only when appropriate evidence actually
exists and the responsible reviewer has approved the wording.
